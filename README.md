# مبيعاتي - واجهة نظام إدارة المبيعات اليومية

واجهة أمامية احترافية بـ React + TypeScript مع رسوم بيانية، وضع داكن/فاتح، وتصميم متجاوب.

## التقنيات

- **React 19** + **TypeScript** + **Vite**
- **Tailwind CSS** للتصميم
- **MUI (Material UI)** للمكونات
- **React Query** لجلب وإدارة البيانات
- **Redux Toolkit** لحالة التطبيق (المصادقة، الثيم)
- **Recharts** للرسوم البيانية (أعمدة، دائرة، خط)
- **React Router** للتنقل

## التشغيل

### المتطلبات

- Node.js 18+
- تشغيل الباك إند Laravel على `http://localhost:8000` (أو ضبط `VITE_API_URL` في `.env`)

### التثبيت والتشغيل

```bash
npm install
cp .env.example .env   # ثم تعديل VITE_API_URL إن لزم
npm run dev
```

التطبيق يعمل على: **http://localhost:5173**

### البناء للإنتاج

```bash
npm run build
```

الملفات الناتجة في مجلد `dist/`.

## المميزات

- **لوحة تحكم**: بطاقات إحصاءات (مبيعات اليوم/الشهر، عدد الفواتير، البائعون)، رسم بياني أعمدة للمبيعات حسب التاريخ، رسم دائري لتوزيع المبيعات، رسم خطي لاتجاه المبيعات.
- **الفواتير**: قائمة الفواتير مع فلترة بالتاريخ، إضافة فاتورة جديدة مع بنود متعددة، عرض تفاصيل الفاتورة.
- **الإشعارات**: قائمة الإشعارات (تجاوز الهدف، تنبيهات) وتحديد كمقروء.
- **البائعون (للإدارة فقط)**: قائمة البائعين وإضافة بائع جديد.
- **المصادقة**: تسجيل الدخول، التسجيل، نسيت كلمة المرور، استعادة كلمة المرور.
- **الوضع الداكن/الفاتح**: تبديل من الهيدر أو من الإعدادات، مع حفظ الاختيار.
- **متجاوب**: يتكيف مع الجوال والتابلت والديسكتوب؛ القائمة الجانبية تتحول لدرج على الشاشات الصغيرة.

## هيكل المشروع

- `src/lib/api.ts` — عميل API وواجهات TypeScript
- `src/store/` — Redux (auth, theme)
- `src/theme/` — ثيم MUI (فاتح/داكن)
- `src/components/layout/` — الهيدر، القائمة الجانبية، التخطيط الرئيسي
- `src/pages/` — صفحات التطبيق (لوحة التحكم، الفواتير، الإشعارات، الإعدادات، البائعون، تسجيل الدخول، إلخ)
